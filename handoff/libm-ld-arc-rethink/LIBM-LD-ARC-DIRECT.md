## The change

asinl 6.25x and acosl 3.17x the reference's cycles on Ivy Bridge (644/103, 669/211; report.md); target <= 2.5x
(asinl <= 258 cycles, acosl <= 528). Contract unchanged: D-10.19 (correctly rounded, every mode), D-10.75's rounding
test at 2^-92 with the 384-bit route behind it.

1. Stall first (own commit, own counts): remove the MXCSR read (`liella_machine_mxcsr_get`, `stmxcsr`) from the
   asinl/acosl path. Locate the call site in our own code (objdump of an asinl probe build; it is reached with the
   boundary's `sqrtsd` root seed). Seed the root without SSE flag traffic that needs reading back (integer seed, or
   fold the flags the way atan2l's path does), never by dropping a flag the caller must see. Gate: on the Ivy
   Bridge timing host `perf stat -e idq.ms_uops:u` on asinl falls from ~67 to ~10 per call and the throughput loop
   overlaps (thr < 0.85 x fenced latency). Expected asinl ~520-540, acosl ~530-550 cycles.
2. Prototype B's kernel before wiring it (go/no-go): asin(c_j + d), c_j = j/128 on [0, 1/2] (65 entries),
   |d| <= 2^-8, Taylor coefficients from the recurrence (1 - c^2)(n+2)(n+1) t_{n+2} = (2n+1)(n+1) c t_{n+1} + n^2 t_n,
   generated by `cargo xtask tables` at 200 digits; terms n <= 7 in 128/64-bit fixed point (Horner), n >= 8 in
   `double` (Estrin); j = 0 is the odd series at 0. Measure the kernel alone in cycles on the Ivy Bridge host (warm
   and cold table). Go if the kernel is <= 100 cycles and the table <= 8 KiB; otherwise fall back to B3 (report.md:
   addition formula, 3 KiB table, root on every call) and say so.
3. Wire it: |a| <= 1/2 the kernel; |a| > 1/2 asin a = pi/2 - 2 asin sqrt((1 - |a|)/2) with (1 - |a|)/2 exact and
   D-10.75's root (seed + one exact integer residual); acosl from the same kernel (pi/2 - asin a for |a| <= 1/2,
   2 asin sqrt((1 - a)/2) for a > 1/2, pi - that for a < -1/2). atan2l/atanl keep Tang's arc kernel.
4. Proof in the module documentation (steps as D-10.75's): table, coefficient, truncation, fixed-point and double
   tail errors, the half-angle doubling and root term; proved bound <= 2^-96 relative; the rounding test unchanged.
   New decision record (`cargo xtask records new decision D-NEW --series D-10 --story LIBM-LD-ARC-DIRECT`,
   `amends` D-10.75), method justified by the papers (Tang ARITH 10 1991; Brent-Zimmermann ch. 3-4; Muller,
   Elementary Functions ch. 2), never by the reference.

## Tests and plants

- Agreement with the 384-bit route on 10^7 operands per function in all four modes, half in the hard regions
  (|a| near 1/2, near 1, tiny), 0 mismatches, undecided counted; constants pinned against the 384-bit arithmetic.
- Plants (`cargo xtask plants`, msg regexes naming the failing test): a wrong last table word; the half-angle
  `pi/2 -` replaced by `pi/2 +` for a < 0 only; one coefficient's lowest fixed-point word dropped; the double tail
  started one term late; the j = 0 branch taken for j = 1; the MXCSR change folding no flags (a flags test must
  catch a lost FE_INEXACT).

## Jobs

Direct-tier gate, plants, `--counters` for asinl/acosl/atan2l (atan2l must not get slower), and a booked Ivy Bridge
cycle run with `handoff/libm-ld-arc-rethink/run_probe.sh` (glibc and Liella binaries) after steps 1 and 3. The
boundary phase split (enter vs decode, rounding vs exit) needs xtask's start-up-state check fixed first (see the
handoff's INFORMATIONAL); story C (fixed boundary cost, ~240 fenced cycles shared by every x87 function) follows.
