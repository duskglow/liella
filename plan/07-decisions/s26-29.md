#### §26–§29

| D-26.1 | §26.1 | HIST | **Internal:** `Logger` handle (owned ident, explicit facility), with an optional structured journald protocol. **Boundary:** the global logger keeps the ident *by pointer*, as the contract says. The connection is synchronised (observable, stricter). |
| D-26.2 | §26.1 | HIST, ARB | **syslog (phase 13); decisions.** `liella::log::Logger` (owned ident, options, facility, mask, channels); the global logger `legacy::log_compat::GLOBAL` keeps the ident by pointer under one lock over settings, connection and delivery; a fork child resets the lock and shares the connection. **Never blocks indefinitely:** sends use `MSG_DONTWAIT\|MSG_NOSIGNAL` and `ppoll` with at most 1 s per message, and the console is opened `O_NONBLOCK` with the same bound (the reference blocks on a full receiver or a FIFO console with no reader); a timeout counts as not delivered (`LOG_CONS` then writes to the console). One reconnect and resend on any other failure. The socket is moved to descriptor 3 or above. The stream transport cuts the text at the first NUL. `errno` is never changed (X3; the reference leaks it after a failed send). A NULL format logs nothing (the reference crashes). Kept from the reference: the extra "unknown facility/priority" record for stray priority bits, `openlog` replacing the options, facility 0 accepted, `closelog` resetting only the ident, `setlogmask(0)` querying; timestamp per `localtime_r`, English month names; console form `IDENT[PID]: MSG\r\n`. The journald protocol of D-26.1 is not built (optional). `openlog(NULL)` selects the program name, also after an earlier `openlog` with another ident (openlog(3); owner ruling 2026-10-04; the reference keeps the previous ident: recorded in `syslog_products`). |

| D-27.2 | §27.1 | HIST | **Internal:** `Result`. **Boundary:** per-thread `dlerror` state. |
| D-27.3 | §27.1 | — | Library search reads the system `ld.so.cache` through its inspected format (Appendix D, phase 14), with `ld.so.conf` directory scanning as the fallback. |
| D-27.4 | §27 | — | **`dl_iterate_phdr`** (static programs, until the loader of phase 14 supplies the object list): one callback for the main program (name "", `AT_PHDR`/`AT_PHNUM`, `dlpi_addr` from `PT_PHDR`, TLS module 1 and the calling thread's block when `PT_TLS` exists), then one for the vDSO (`linux-vdso.so.1`, ELF64 header fields e_phoff at 32, e_phentsize 54, e_phnum 56) when `AT_SYSINFO_EHDR` is set, as a glibc static program reports (probe); `dlpi_adds` = objects, `dlpi_subs` = 0, `size` = 64; a non-zero callback result stops the walk and is returned; it reads immutable startup data only (async-signal-safe). **`stime`** is compat-only as in glibc 2.39: `libc.so` exports `stime@GLIBC_2.2.5` (non-default; `.symver` stub in `s23_time.rs`, listed in the version script by `cargo xtask so`), `libc.a` offers no plain `stime`, so no new program links it while old binaries resolve it. Known difference: `libc.so` binds `dl_iterate_phdr` GLOBAL where glibc binds WEAK (the same for every WEAK export, e.g. `fgetc`). Probes: CONF-SYMS-2. |
| D-27.5 | §27.1 | — | **`_dl_find_object`** (static programs, until phase 14): a `pc` in one of the main program's `PT_LOAD` segments gives that segment's range (a static glibc 2.39 program reports the segment, not the whole object), one in the vDSO the vDSO's whole mapped range; `dlfo_eh_frame` = the object's `PT_GNU_EH_FRAME` address (0 without one), `dlfo_flags` 0, result 0; any other `pc` (stack, past `_end`, 0) gives -1 and leaves `*result` alone. libgcc_eh (GCC 13) calls it, so a static C++ or `-fexceptions` program needs it to link. Exported with feature `runtime` only (`export! { runtime ... }`): the answer covers only a process Liella started, so test builds that interpose exports on a host process keep the host's (interposed, it hid the host's shared objects from Rust's panic unwinder: SIGABRT). Known gap: `dlfo_link_map` is 0 (no `struct link_map` before phase 14; glibc gives a non-null one). Probe: PTHREAD-ONCE-UNWIND-2 (static and dynamic glibc). |
| D-27.6 | §27.5 | — | **`__x86_get_cpuid_feature_leaf@GLIBC_2.33`** (`<sys/platform/x86.h>`, behind `CPU_FEATURE_PRESENT`/`CPU_FEATURE_ACTIVE`): returns `struct cpuid_feature` (32 bytes, align 4: the raw CPUID words eax, ebx, ecx, edx, then the "active" words in that order). Index to leaf: 0=1, 1=7.0, 2=0x80000001, 3=0xd.1, 4=0x80000007, 5=0x80000008, 6=7.1, 7=0x19, 8=0x14.0, 9=0x24. A leaf or subleaf past the CPU's maximum reads zero. Index 10 and above (including 0xffffffff) gets one shared all-zero entry, never NULL. The table is filled on the first call (`liella_rt::cpu::feature_leaves`). Active = present AND a fixed per-bit rule: the `ACTIVE_ALWAYS` bits; FMA/AVX/F16C/AVX2 only with XCR0 SSE+AVX state; AVX-512 F/DQ/CD/BW/VL only with XCR0 0xe6; HLE/RTM inactive and RTM_ALWAYS_ABORT active (even though not present) when 7.EDX bit 11 or 13 is set. Probe: X86-CPUID-FEATURE-LEAF (glibc 2.39 on Skylake-SP host Skylake-SP, Haswell-EP host Haswell, Broadwell-EP host Broadwell, Zen 1 host). **Known gaps (ruling #778, #781, #782):** (1) an active bit never seen present on a probed CPU stays inactive (AVX512_IFMA/VBMI/VNNI/BITALG, GFNI, VAES, VPCLMULQDQ, the 7.1, 0x19, 0x14 and 0x24 active bits, among others). This is the safe answer: a feature is never claimed usable when it is not. Trigger: extend `ACTIVE_ALWAYS` once a newer CPU (Ice Lake+ / Zen 4) can be probed against glibc. (2) The TSX rule (abort bit 11 or 13) rests on one CPU per side (Skylake-SP host with bit 13, Broadwell-EP host without either bit). A model-based rule cannot be told apart on these hosts. (3) `glibc.cpu.hwcaps` tunable masking of the active bits is not implemented. |
| D-27.7 | §27 | SEC | **The loader's ELF reader (`liella_ld::elf`, IP-24 part 1, DL-ELF-READ-1): error rules.** Input is a byte slice; no I/O, no allocation, no panic, no read outside the slice; every offset, count and size is checked with checked arithmetic (threat-model rule 4). `Elf::parse::<A: Arch>` checks, in this order, and returns the first failure as a typed `ElfError`: length >= 64 (`TooShort`); magic; `EI_CLASS` = `A::EI_CLASS` = ELFCLASS64 (`WrongClass`, s27_1_f_0); `EI_DATA` = `A::EI_DATA` (`WrongData`; fields are decoded in that byte order); `EI_VERSION` = 1; `EI_OSABI` System V or GNU; `e_type` `ET_EXEC` or `ET_DYN`; `e_machine` = `A::E_MACHINE` (identity only through `liella_ld::arch`, design §0a); `e_version` = 1; `e_ehsize` = 64; `e_phnum` != `PN_XNUM` (section headers are never read); `e_phentsize` = 56 unless `e_phnum` = 0; the program header table inside the slice and not overlapping the ELF header; then per program header in index order: `p_offset + p_filesz` and `p_vaddr + p_memsz` do not overflow, `p_align` 0 or a power of two, `PT_LOAD` `p_filesz <= p_memsz`, the file ranges of `PT_DYNAMIC`/`PT_INTERP`/`PT_NOTE` overlap neither the ELF header nor the table, at most one `PT_DYNAMIC` and one `PT_INTERP`. Segment contents are checked when read (the slice may be a file prefix): a range outside the slice is `OutOfRange`; `PT_INTERP` is a non-empty path with exactly one NUL, at the end; `PT_DYNAMIC` is a multiple of 16 bytes and holds a `DT_NULL` (entries after the first `DT_NULL` are never read); `DT_STRTAB` and `DT_STRSZ` at most once each, both or neither, and both when a string-valued tag (`DT_NEEDED`, `DT_SONAME`, `DT_RPATH`, `DT_RUNPATH`) is present; the string table lies wholly in the file-backed part of one `PT_LOAD` (`AddressNotMapped`); a string offset is below `DT_STRSZ` and its NUL inside the table. Notes are padded to 8 when `p_align` is 8 and to 4 when it is 0-4 (any other value is `BadNoteAlign`); a note header, name or descriptor past the segment end is `NoteTruncated`, a non-empty name without a final NUL `BadNoteName`; `NT_GNU_PROPERTY_TYPE_0` properties are 8-aligned and a property past its descriptor is `PropertyTruncated`. Iterators yield `Result` and stop after the first error. Semantic segment checks (order, congruence, overlap of `PT_LOAD`s) belong to the mapper (§3); dlerror texts wait for the M14-0/DL-0b probes. Tests: `crates/ld/tests/elf_reader.rs` (malformed corpus), `elf_readelf_parity.rs` (readelf -h/-l/-d/-n). |
| D-27.8 | §27 | SEC | **The loader's ELF reader, part 2 (`liella_ld::elf`, IP-24 part 2, DL-ELF-READ-2): hash tables, versions, relocation iterators.** Same input rules as D-27.7 (no I/O, allocation, panic or read outside the slice; checked arithmetic; iterators yield one error and stop). Tables are found through `Dynamic`: a part-2 tag occurs at most once (`DuplicateDynamic`); address/size pairs (`DT_RELA`/`RELASZ`, `DT_JMPREL`/`PLTRELSZ`, `DT_RELR`/`RELRSZ`, `DT_VERDEF`/`VERDEFNUM`, `DT_VERNEED`/`VERNEEDNUM`) are both or neither (`MissingDynamic(tag)`); `DT_RELAENT` = 24 and `DT_RELRENT` = 8 are required with `DT_RELA`/`DT_RELR`, `DT_PLTREL` = `DT_RELA` with `DT_JMPREL` (`MissingDynamic`/`BadDynamicValue`); a size that is not whole entries is `TableSize`. Fixed-length tables (SysV hash header + `nbucket+nchain` words, GNU hash header + Bloom words + buckets, RELA, RELR) lie wholly in the file-backed part of one `PT_LOAD` (`AddressNotMapped`); tables walked to their end (GNU chain, verdef, verneed, versym) are read within the rest of that segment. GNU hash: at least one Bloom word and a shift below 64 (`BadHashHeader`); a bucket below `symoffset` or a chain past the mapped bytes is `HashIndex`. SysV: a bucket/chain value at or past `nchain` is `HashIndex`, a chain longer than `nchain` `HashChainLoop`; no buckets = empty. Symbol count: SysV `nchain`, else the end of the GNU chain from the highest bucket (all buckets empty: `symoffset`, a lower bound). Versions: revision 1 (`BadVersionRevision`); a chain ending (next 0) before its count is `VersionCount`, an entry past the segment `VersionTruncated`; names through the string rules of D-27.7; a `versym` index above the highest `vd_ndx`/`vna_other` (hidden bit masked) is `VersionIndex`, an entry past the mapping `SymbolIndex` (the count is a hint, not a bound). RELA entries are classified only through `Arch::classify` into `RelocKind`; an unknown type is `Unsupported(n)` and still yielded (design §0a); `TextRel` carries width, pc-relative and signed (32 vs 32S). RELR: an even entry is an address, an odd entry a 63-word bitmap after the previous address or bitmap; a bitmap with no address before it is `RelrNoBase`, an address past 2^64 `RelrOverflow`. Tests: `crates/ld/tests/elf_tables.rs`, `elf_readelf_parity.rs` (readelf -r/-V/--dyn-syms). |

| D-29.2 | §29.1 | COMPAT | **UDP RPC replies from the called address only** (owner ruling 2026-10-23, #1643, provisional): the UDP client compares each datagram's `recvfrom` source (port and IPv4 address) with the called address and drops any other, whatever its xid; the socket is not connected (that would change ICMP error reporting). A reply-shaped datagram (type REPLY, status accepted or denied; the xid is never consulted) from another address during a call turns its timeout into `RPC_CANTRECV` with `EREMCHG`; nothing ends a call early. Each call's xid is fresh random bits (`getrandom`), except the call after `CLSET_XID`, which is stepped from the set value as probed. Opt-out COMPAT-12 (`liella.compat.rpc_reply_any_source=1`, ignored when `AT_SECURE`). `clnt_broadcast` and TCP are not affected. Reason: replies over UDP are matched by xid only; accepting them from any source lets a third party who can send packets to the client answer in the server's place. |
