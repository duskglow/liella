#### §20: Signals

| ID | Spec | Ann. | Decision |
|---|---|---|---|
| D-20.1 | §20.1 | HIST | **One** reserved real-time signal (32), multiplexing cancellation and credential broadcast with a per-thread request word. `SIGEV_THREAD` timers need no signal (D-23.3). So `SIGRTMIN` = 33 (observable; programs obtain it through `__libc_current_sigrtmin`). OD-8 records the fallback of reserving two. **Verified 2026-10-04 (OD-8 ruling):** `conformance/c/s20_internal_signal.c` (run by clause tests `s20_1_c_2`, `s20_2_f_0`, `s20_3_g_0`) reads the kernel's mask and action raw after every route: `sigprocmask`, `pthread_sigmask`, `sigblock`, `sigsetmask`, an action's `sa_mask`, `setcontext`/`swapcontext` masks, `signalfd`, `sigsuspend`, `sigwaitinfo`/`sigtimedwait`, `posix_spawn` `SETSIGMASK` never block 32; `sigaction`, `signal`, `sigset`, `sigignore`, `sighold`, `sigrelse`, `siginterrupt` on 32 are `EINVAL`; no reported set (masks, `sa_mask`, `sigpending`, spawn attributes, `getcontext`) contains it; it has no name and no real-time text. Two fixes: `setcontext` and `swapcontext` installed the context's mask as given (a context mask with bit 32 blocked it); they now install a copy with 32 cleared (`machine/context.S`). `raise(32)` is `EINVAL` (it was sent; glibc refuses its own internal signals in `raise`, `pthread_kill`, `pthread_sigqueue`). `kill`, `tgkill`, `sigqueue` and `killpg` stay the kernel's, as glibc's: 32 sent to a Liella process reaches the library's handler, which ignores a signal without a request. |
| D-20.2 | §20.2 | KERN | The restorer trampoline is a C-layer machine primitive (`machine/restorer.S`, ⚑ KERN). Internal dispositions are a typed enum in `rt::signal`. |
| D-20.3 | §20.3 | ARB, HIST | **Internal:** `SigSet` is a `u64`. **Boundary:** `sigset_t` stays 128 bytes (ABI). Bits beyond 64 read as zero and are ignored on input. |
| D-20.4 | §20.2 | HIST | `signal` has BSD semantics. `sysv_signal`, `sigset`/`sighold`/`sigrelse`/`sigignore`, `sigvec`, `sigblock` and the two `sigpause` forms are legacy translations. |
| D-20.5 | §20.9 | HIST | The internal preferred interface is `SignalStream` (signalfd-backed) for synchronous handling. |
| D-20.6 | §20.2 | KERN | **IP-16's "dispatch table" (accepted 2026-10-01):** user handlers are installed in the kernel directly, with the library's restorer, and the kernel's record is the only copy of a user disposition (no table that could drift from it, for example after `SA_RESETHAND`). The rt table holds the library's own handler for the internal signal, which phase 6 installs. |
| D-20.7 | §20.2, §20.3 | HIST | C `struct sigaction` and the 1024-bit `sigset_t` are converted in `legacy::signal_compat`. The ABI crate models `sa_handler`/`sa_sigaction` as a union whose fields only `unsafe` code may read, so legacy defines `CSigaction` with the same layout (tested). The internal signal is never set, blocked, reported, accepted by a wait, or put into a filled set. |
| D-20.8 | §20.4 | HIST | **`pthread_kill` and `pthread_sigqueue` (milestone 5, 2026-10-04).** Both target one thread through `tgkill`/`rt_tgsigqueueinfo`; signal 0 only checks; an invalid signal (and the internal signal 32, D-20.1) is `EINVAL` returned with `errno` untouched. A thread that has exited but not been joined: `pthread_kill` returns 0 and sends nothing, as §20.4's Failure clause says for 2.34+ (**found and fixed:** it returned `ESRCH`, including when the thread exits between the lookup and `tgkill`); `pthread_sigqueue` returns `ESRCH`, as the reference does and pthread_sigqueue(3) says ("thread is not valid"). `conformance/c/s20_pthread_kill.c` checks all of it and passes against the reference too (clauses `s20_4_c_5`, `s20_4_f_0`). |
