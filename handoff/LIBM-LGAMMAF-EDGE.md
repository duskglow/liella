## Findings that hold on either base (analysis only, no code; for the continuation)
1. **Below -42 lgammaf has no cancellation.** Every float at or below -2^23 is an integer (a pole). Take a
   non-integer float x in (-2^23, -42) and let X = -x. Then lnΓ(x) = A - lnΓ(X), where A = ln(π/(X·|sin πx|)),
   because Γ(1-x) = X·Γ(X) > 0.
   - Upper bound on A. For X in [2^e, 2^(e+1)), X is a multiple of 2^(e-23), so its distance d to the nearest
     integer is at least 2^(e-23), and |sin πd| ≥ 2d. Then X·|sin πx| ≥ 2^(2e-22) ≥ 2^-12 (e ≥ 5), so
     A ≤ ln(π·2^12) < 9.47.
   - Lower bound on A: A ≥ ln(π/X) > -14.8.
   - lnΓ(X) > lnΓ(42) = ln(41!) > 114.03, so y < -104.5.
   No float below -42 lies near a zero of lnΓ (those zeros are within about e^-104 of the integers), so the brief's
   cancellation case does not arise there.
2. **Error budget of the reflection formula in `double`** (a sketch; the proof goes in the doc comment).
   - lnΓ(X) comes from the existing Stirling branch (X ≥ 36, X an exact float): ≤ 29.1u relative.
     Since lnΓ(X) = |y| + A ≤ 1.091·|y|, this is < 31.8 ulp of y.
   - A = -ln64(X·s·(1/π)), where s = |sin πr| and r = x - 2·round(x/2) is exact (|x| < 2^23); t = min(|r|, 1 - |r|).
     With the relative error of v about 5u (product, constant, and a sinpi kernel of ≤ 2u, assumed), plus ln64's
     (1.45 + 2|A|)u < 31.1u, A is accurate to < 37u absolute. That is < 0.3 ulp of y, because |y| ≥ 64 gives
     ulp(y) ≥ 2^-46 = 128u.
   - The final subtraction adds 0.5 ulp, so the total is ≤ 33 ulp of y. LGAMMA_DELTA = 72 covers this; a margin of
     36 would halve the refusals.
   - Sign: sign Γ(x) = sign sin πx = sign r, read from the exact reduction with no integer conversion (D-10.95).
3. **`fast_gamma::lgamma_kernel` cannot be the second try below -42.** It is the f64 double-double kernel and covers
   |x| < 16 only (`fast_gamma::HI = 16`, `domain`). So a refusal below -42 needs the exception table, or a
   double-double reflection as its second try.
   - Expected refusals for a margin of d ulp of y, with f32 boundaries 2^29 double ulp apart: about 2d/2^29 per
     operand per mode.
   - Operands: the non-integer floats in (-2^23, -42) number 22·2^18 - 22 + 17·2^23 - (2^23 - 64) = 139 984 938.
   - With d = 72 that gives ≈ 38 per mode (≈ 150 operands over the four modes); with d = 36, ≈ 19 per mode.
   - A table keyed by x that holds y to well beyond 2^-60 relative serves all four modes.
