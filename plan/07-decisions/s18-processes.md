#### §18: Processes

| ID | Spec | Ann. | Decision |
|---|---|---|---|
| D-18.1 | §18.2 | HIST | Internally, **spawn is the primary creation primitive**. `fork` is exported with atfork and full library-lock handling, so `malloc` works in the child, per the contract. **`vfork` (owner ruling 2026-10-22, #410, VFORK-CLONE-VM; supersedes the copy-on-write `vfork`):** as glibc, `SYS_vfork` (= `clone(CLONE_VM\|CLONE_VFORK\|SIGCHLD)`): the child shares the caller's memory and stack and the caller is suspended until the child calls `execve` or `_exit` (the only things a child may do, POSIX). No page-table copy and no copy-on-write left on the parent's pages (F24). `vfork`/`__vfork` are assembly (`csys/src/machine/vfork.S`, products only): the return address is popped into a register before the syscall and pushed back after, since the child's return overwrites that stack slot; no signal is blocked (as glibc); an error tail-jumps to the local Rust `liella_vfork_fail` (errno, -1). Tests: `conformance/c/s18_vfork.c` (shared write, exec, failed exec 127, no faults on rewrite after a 64 MiB parent's vfork, masks unchanged, `EAGAIN` under `RLIMIT_NPROC`), `s18_fork.c`, `s18_fork_aliases.c`. |
| D-18.2 | §18.3 | HIST | **Internal:** `liella::process::search(name, PATH, exec, shell)`. A name containing `/` runs as given; an empty name is `ENOENT`. An unset `PATH` means `/bin:/usr/bin` (no cwd); an empty element means the cwd. `ENOENT`/`ENOTDIR` continue; `EACCES` continues and is reported last; any other error ends the search (exec(3)). Candidates are built on the stack; one over `PATH_MAX` is `ENAMETOOLONG` and stops. `ENOEXEC` runs `/bin/sh file argv[1..]` for the exec `p` forms; the spawn forms return it (GLIBC_2.15; the 2.2.5 compat versions wait for phase 15). The exec forms pass the caller's arrays to the kernel unchanged; the `l` forms collect their list through the C layer's va_list accessor (512 entries on the stack, the heap beyond). `fexecve` is `execveat(fd, "", AT_EMPTY_PATH)` with no `/proc` fallback (OD-5); a negative fd or NULL array is `EINVAL` (fexecve(3)). |
| D-18.3 | §18.4 | PATH | **Internal:** file actions are `liella::process::FileAction`, byte-encoded in a caller-heap block (`__actions`/`__used`). Every descriptor an action names is checked when it is added (`EBADF` if negative or ≥ `RLIMIT_NOFILE`, `addfchdir_np` included: glibc accepts -1 and fails in the child; KNOWN). Attributes keep the `posix_spawnattr_t` layout; `setflags` takes 0x1ff; `setschedpolicy` takes every policy `sched_setscheduler` accepts (0, 1, 2, 3, 5; glibc refuses BATCH and IDLE; KNOWN). **Creation (owner ruling 2026-10-09, SPAWN-VFORK):** the caller blocks all signals; `clone3(CLONE_VM\|CLONE_VFORK\|CLONE_CLEAR_SIGHAND[\|CLONE_PIDFD\|CLONE_INTO_CGROUP])` makes a child that shares the caller's memory (no page-table copy) and runs `boundary::spawn::child_main` on a private 128 KiB mmap'd stack (`liella_machine_clone3_run`, the single new unsafe site is `conv::spawn_entry`). The child allocates nothing, takes no lock, uses no stdio, writes no thread-local state and runs no handler (cleared at creation, all blocked until the final mask); it only reads the context on the suspended caller's stack and reports its error through a word there (no shared mapping); no fork handler or cancellation runs. On `ENOSYS` the old copy-on-write path (`clone(CLONE_VFORK)`, shared word, manual handler reset; untested) is used. User-visible `vfork()` keeps D-18.1. Safety lives in: `conformance/c/s18_spawn_vm.c` (exact errnos, no leftover child, heap unchanged by spawns, group signals under load), with planted bugs (child allocates, signals unblocked, errno lost) failing it. Child order: SETSIGDEF, SETSID, SETPGROUP, scheduling, RESETIDS, the actions in order, the mask, exec (the `p` search after the actions). On a child error the child exits 127, the parent reaps it, closes the pidfd (glibc leaks it; KNOWN) and returns the error. |
| D-18.4 | §18.6 | HIST | **Internal:** `liella::process::ChildStatus` (Exited/Killed/Stopped/Continued) with `word`/`from_word`. **Boundary:** the waits pass the kernel's status word through and write `*status` only when a child is reported. Every wait is a cancellation point (`wait4`/`waitid` by number). `si_status` is what the kernel gives: 8 bits for exits (⚑ KERN; §18.6 corrected by owner ruling 2026-10-03). |
| D-18.5 | §18.7 | HIST | `system`/`popen` spawn `/bin/sh -c` through D-18.3. `system`'s SIGINT/SIGQUIT handling is reference-counted in `boundary::spawn` (the first caller ignores, the last restores); SIGCHLD is blocked in the calling thread only; the shell gets the original mask and SIGINT/SIGQUIT at default unless they were ignored before. An unexecutable shell is status 127 with `errno` untouched (glibc leaves `EACCES`; KNOWN). `system` is a cancellation point: a cancelled caller kills and reaps the shell, restores the dispositions, then acts. `popen` keeps a locked (stream, pid, fd) list held through the call; the child closes the other popen descriptors; the mode is exactly one of `r`/`w` plus at most one `e`, in any order. `pclose` is not a cancellation point (POSIX's "may" list, the spec's per-section listing, and the reference agree). `pclose` of a stream not from `popen` closes it and fails with `ECHILD` (pclose(3); glibc returns 0; KNOWN). The locks join fork's order (D-18.6). |
| D-18.6 | §18.2 | HIST | **`fork` mechanics** (phase 6). *Prepare* `atfork` handlers run in reverse registration order, then the library's locks are taken in one documented order (the atfork list, `popen`'s list and `system`'s count (D-18.5, phase 11), the stdio list, the thread list, the stack cache, the setxid broadcast, the time zone, the heap with `Heap::lock_all` and its cache pool, the environment lock). `clone(SIGCHLD \| CLONE_CHILD_SETTID \| CLONE_CHILD_CLEARTID)` names the thread block's TID word. In the parent the locks are released and the *parent* handlers run. In the child the locks are released (it is their only thread), the thread list is reset to the calling thread, the other threads' heap caches are parked in their pools (their slabs stay usable, M4), the stack cache keeps only stacks whose threads had already exited, the robust list is registered again (the kernel does not inherit it), `popen`'s and `system`'s locks are reset and a `system` count left by a parent thread is cleared with SIGINT/SIGQUIT given the dispositions it saved (also after `_Fork`), and the *child* handlers run. `_Fork` does only the `clone` and the child's list, robust-list and TID resets: no handlers and no locks (it is async-signal-safe). |
| D-18.7 | §18.5, §18.8, §18.9 | HIST | `pidfd_getpid` parses `/proc/self/fdinfo`: not a pidfd or not open is `EBADF` (without `/proc`, an open descriptor is `ENOSYS`, D-X.12), a reaped process `ESRCH`, `Pid: 0` (another PID namespace) `EREMOTE` (probed). Groups and sessions are thin. `daemon` uses Liella's `fork` (handlers and locks); the parent does `_exit(0)` without flushing (daemon(3)); the child does `setsid`, `chdir("/")` and `/dev/null` (O_RDWR) on 0–2; only `fork` and `setsid` errors are reported. `prctl`, `ptrace` and `arch_prctl` pass the caller's arguments through `raw`; `PTRACE_PEEK*` returns the word and leaves `errno` untouched on success; `prctl` and `personality` results are truncated to `int`. Known limits: a setxid broadcast waits while a spawning thread is suspended in its vfork child. |
