# /dev/shm/claude). The five plants of -2 (handoff/LAYOUT-TRACE-HOST-CANONICAL-2-plants.txt) with this host's RAM
# paths: each command traces every regen probe (regen.sh --trace-only) against a RAM copy of the role's fast
# products (built from this tree); the tracer under test is the plant copy's. Then the runner's environment
# hand-off, caught by the xtask unit test this run fixed.

# lthc3-locale-host: the locale archive is the host's, not the tree's en_US.UTF-8 archive.
