## The change

Clause: `s10_0_c2_0` (`__<name>_finite` remain as compat symbols with the same contract as `<name>`, restricted to
finite arguments). It is a pending `clause!` stub in `crates/math/tests/s10_math_clauses.rs`.

Liella code (exists today): the generated `crates/libm-so/compat_aliases.S` (`@generated by cargo xtask compat-gen`
from the libm.so.6 `alias` rows of `spec/abi/compat-plan.tsv`; generator `xtask/src/compat.rs`). Each
`liella_compat___<name>_finite_GLIBC_2_15` (and the f128 ones at 2.26) is a frame-free jump to the current function.
A wrong target row (for example `__exp_finite` jumping to `exp2`) would ship silently today.

First check: `fam_finite` in `crates/boundary/tests/s10_math_symbols.rs` calls `products::math_family("finite")`.
Read what that family covers; if it already calls every `__*_finite` alias and compares it with `<name>`, add the
clause ID to it (tag fix), make `s10_0_c2_0` a test that runs the same check, and stop there.

Otherwise, test to write (`s10_0_c2_0`, no dynamic loader needed): build `target/liella/libm.so.6`
(`cargo xtask so`), list its dynamic symbols with versions, and for every `__<name>_finite@GLIBC_*` check that
(1) it is a non-default version (cannot be linked against), (2) the `alias` row of compat-plan.tsv names `<name>`
as its target, and (3) the stub's jump target address equals the address of `<name>`'s default-version symbol in the
same file (decode the stub's one `jmp rel32` from the section bytes; this reads Liella's own object, not glibc).
Also check the set of `_finite` names equals the spec's Appendix B `_finite` rows (`spec/symbols.tsv`). Skip with a
printed reason only when `libm.so.6` was not built.

Plants (each under `timeout 600`, RAM copy, fresh directory, restore with `cat backup > file`, then regenerate with
`cargo xtask compat-gen` in the copy): (a) change the `__exp_finite` alias row's target to `exp2` -> CAUGHT;
(b) drop the `__logf_finite` row -> CAUGHT (set mismatch); (c) give `__sqrt_finite` a default version in the
generator's output -> CAUGHT. Script exits non-zero on a survivor.
