| OD-C3 | **Resolved: cross-language LTO works and is adopted for release products.** Measured 2026-09-30 on an i9-14900KF (rustc 1.98.1 on LLVM 22.1.8; clang-22 and lld-22 at 22.1.8; best of 5 runs). **Without LTO** (gcc-built C layer): system call `getppid` 44.1 ns inline vs 46.5 ns through the wrapper; thread-pointer read 0.18 vs 0.72 ns; bare call into C 0.72 ns. **With LTO** (C layer as LLVM bitcode, `-Clinker-plugin-lto`, lld): thread-pointer read 0.18 ns through C, identical to inline assembly; bare call 0.24 ns; no wrapper symbol survives in the binary (all three exist without LTO); the system-call loops compile to identical instructions (`mov $0x6e,%eax; syscall`), so the remaining ~2 ns difference between them is measurement noise. **Decision:** release products build `csys` with clang at rustc's LLVM version and link with `-Clinker-plugin-lto`, which removes the F44 and F47 costs. Test and dev builds may use any C compiler. `cargo xtask so` checks that clang's LLVM major version matches rustc's and fails otherwise. |
