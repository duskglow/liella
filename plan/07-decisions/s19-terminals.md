#### §19: Terminals

| ID | Spec | Ann. | Decision |
|---|---|---|---|
| D-19.1 | §19.1 | HIST, KERN | **Internal:** `liella::term::Termios` is the kernel's `termios2` (integer rates; any rate via BOTHER), through `TCGETS2`/`TCSETS2`. **Boundary:** the glibc `struct termios` with B* codes in `c_cflag`; `c_ispeed`/`c_ospeed` hold the kernel's rates (`ISPEED_ZERO` = `UINT_MAX` records `cfsetispeed(0)`), converted in `abi::pack`. `tcsetattr` reads, sets and re-reads the settings: `EINVAL` when no requested change was taken, success when nothing was to change (as the reference, probed). A BOTHER code without a rate keeps the terminal's rate (as `TCSETS` does). Mode words pass unchanged (glibc clears `c_iflag` bit 31, which it uses for "input speed 0"; KNOWN). Known effect: a struct read from one terminal with BOTHER and applied to another carries the first terminal's rate. `tcsendbreak`: `TCSBRK 0` for a duration ≤ 0, else `TCSBRKP` with ceil(d/100). Cancellation points: `tcdrain`, `posix_openpt`, `getpt`, `openpty`, `forkpty`. |
| D-19.2 | §19.4 | HIST | `openpty` opens `/dev/ptmx` (`O_RDWR\|O_NOCTTY`), unlocks it and opens the slave with `TIOCGPTPEER` in one step; `termp` is applied as `tcsetattr` would (as far as the slave takes it; `errno` untouched on success, glibc leaves `EINVAL`) and `winp` with `TIOCSWINSZ`. NULL descriptor pointers are `EFAULT` with nothing opened (S6; glibc crashes; KNOWN). `posix_openpt` refuses `O_DIRECTORY`, `O_PATH`, `O_TMPFILE`, undefined bits and -1 with `EINVAL` (POSIX allows it; glibc passes them to `open`; KNOWN). The four-step API stays as translations; `grantpt` only validates the master. `forkpty` is a runtime-only export like `fork`; `openpty`/`forkpty`/`login_tty` export at GLIBC_2.34, their 2.2.5 versions wait for phase 15. |
| D-19.3 | §19.3 | HIST | `ttyname`: `readlink(/proc/self/fd/N)`, accepted only when that path names the same (dev, ino, rdev); otherwise `ENODEV` (glibc scans `/dev` and reports `ENOTTY` for another devpts instance; 3 KNOWN lines). Without `/proc` (OD-5, D-X.12, 2026-10-04): the name the device number gives (`/dev/pts/N`, `/dev/ttyN`, `/dev/ttySN`, `/dev/tty`, `/dev/console`, `/dev/ptmx`), accepted only when it is the same (dev, ino, rdev), else `ENODEV`. `_r` forms: NULL is `EINVAL` (`ptsname_r(NULL)` crashes glibc; KNOWN), size 0 is `ERANGE` before the descriptor, a short buffer is `ERANGE` and untouched (glibc gives `ENODEV` for a buffer of exactly `strlen(name)` and writes into it; KNOWN); the error is also stored in `errno`. |
| D-19.4 | §19.4, §19.5 | HIST | `login_tty` checks for a terminal before changing anything (glibc has already called `setsid` when it fails), keeps `errno` untouched on success (X3; glibc leaves `EPERM`) and accepts a master (the kernel decides). `/etc/ttys` lines have no length limit and an unterminated last line is an entry (glibc skips lines of 100+ bytes and the last line without a newline; KNOWN/ADDED). `tcflush` and `tcflow` check their argument before the descriptor (as `tcsetattr`'s action; glibc reports `ENOTTY` on `/dev/null`; KNOWN). `tcgetpgrp` on a master nobody controls returns the kernel's 0. `gtty`, `stty` and `revoke` are `ENOSYS`. |
