### Phase 1: Kernel boundary

* **Scope:** Appendix A (A.1 system calls, A.2 interfaces), C0.1 numbering, C0.3, C0.8.
* **Symbols:** none exported yet. `syscall()` itself is exported in phase 5.
* **Tests:** 281 primitive stubs, plus C0 clauses about error numbering and restart semantics.
* **Needs:** P0.
* **Builds:**
  * **C layer:** every class-*sys* wrapper, and the approved *machine* primitives (tp,
    vDSO call).
  * **Rust:** IP-1, IP-3, IP-4; the IP-11 `Sys`/`Machine` traits with `Faulty`; `CSys`;
    the IP-12 `conv`/`ret` core; IP-13 `export!`; the IP-24 ELF subset for the vDSO; and
    `liella_abi::layout` for the Appendix C types.
* **Internal API:**
  * `liella_kernel::Sys` is grouped like Appendix A.1 (process, creds, signal, memory, futex,
    fd, io, poll, sync, lock, fs, mount, socket, time, sched, ipc, random, system).
  * Every method is typed: `Fd`, `KPath`, flag bitsets, `Timespec`, slices, and
    `Result<T, Errno>`.
  * `CSys` implements it through `ffi` (category *extern*: one declaration per wrapper,
    pointer-taking ones private and wrapped with slices).
  * Also covers modern calls the POSIX layer never exports (`openat2`, `clone3`, `futex`,
    `sched_setattr`, `statmount`), per D-24.6 and H17.
* **Test surface:**
  * One integration test per primitive against the real kernel. Cases: success, each
    documented errno reachable without privileges, and argument layout (a `statx` round
    trip, `sigaction` with restorer).
  * `KPath` edge cases: interior NUL gives `EINVAL`; 4,095 bytes pass and 4,096 give
    `ENAMETOOLONG`; the empty path is kept.
  * auxv parsing of synthetic vectors.
  * vDSO lookup when the vDSO is absent.
* **ABI data tests:** 171 Appendix C layout and initializer stubs (`crates/abi/tests`)
  specified and passing against `liella_abi::layout`.
* **Exit:** all 281 primitive tests and 171 layout tests specified and passing (privileged
  ones in the CI container). `csys-audit` is clean. The unsafe audit shows only category
  *extern* sites in `ffi.rs`.
* **Delivered** (exit met, with the deviations listed):
  * **C layer:** 272 class-*sys* wrappers generated from `csys/syscalls.tsv` (19 area files),
    the *machine* primitives in assembly (thread pointer, CPUID/XGETBV, MXCSR/x87, PKRU, barrier,
    vDSO call, call-at-address, signal restorer). `csys-audit` clean.
  * **`liella-kernel`:** `Sys` (269 methods, generated together with `Faulty` by one macro),
    `Machine`, the ownership types of D-X.9 (`Region`, `IoVec`/`IoVecMut`, `MsgHdr`/`MsgHdrMut`,
    `MMsgHdr`, `KPtrArray`, `RemoteIoVec`), typed command sets for the multiplexed calls
    (`ops`), the UAPI structures, auxv and vDSO parsers.
  * **`liella-boundary`:** `CSys` (vDSO for the five clock/CPU calls, resolved lazily from
    `AT_SYSINFO_EHDR`), crate-private `raw`, test-only `selftest`, `conv` (vDSO image, region
    bytes and words, C-caller `buf`/`buf_mut`/`fd`), `export!`.
  * **`liella-abi`:** `layout` generated by `cargo xtask abi-gen` from `spec/abi/layouts.tsv`
    (161 types, typed members laid out by rustc); `layout_init` (the ten static initializers,
    built from member offsets and spec §22 kinds); `ctypes`; the pure `ret` encoders.
  * **Tests:** 281 primitive tests (15 consecutive full-suite runs green), 171 Appendix C tests
    (1,167 member offsets), 10 §0 clause tests (C0.3, C0.8), plus internal suites (kernel types,
    uapi against Appendix C, modern calls, `ret`, `export!`). 486 specified tests in total.
  * **Tooling:** `abi-gen`, `bench` with `bench/budgets.tsv` (all budgets met: thread pointer
    0.76 ns, vDSO `clock_gettime` 16.6 ns against 73.9 ns for the system call), the K5 check
    of `ffi.rs` against `liella_csys.h`, and the sealed-constructor rule in `unsafe-audit`.
  * **Deviations from the plan as written:**
    1. The unsafe audit shows category *slice* sites as well as *extern*: 7 in `conv.rs`
       (vDSO image, region bytes, region words, and the C-caller `buf`/`buf_mut` with their
       inner blocks) and 1 *export* site (`export!`). All are permitted categories in
       permitted files; phase 1 needed the vDSO and `Region` conversions earlier than the
       plan assumed.
    2. `FakeSys` became `Faulty`, a wrapper that injects errors into a real kernel. A full fake
       kernel was not needed.
    3. IP-12 is split. The pure `ret` encoders are done. The boundary wrappers that *store*
       `errno` need the thread block, so they move to phase 4, and C0.1 clauses 0–2 stay
       pending until then.
    4. The vDSO absent case is tested at parser level (`resolve_vdso(0)`, damaged images).
       Booting without a vDSO is not possible in the test environment.
