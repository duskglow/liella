#### C0: Cross-cutting conventions

| ID | Spec | Ann. | Decision |
|---|---|---|---|
| D-C0.1 | C0.1 | HIST, PATH | errno is written only on failure (X3). One `ret` function per convention. **Tests (milestone 5, 2026-10-04):** `conformance/c/s00_errno.c` (clauses `s0_6_c0_1_0` to `s0_6_c0_1_2`): the sentinels with positive codes, `errno` per thread, the entries that say otherwise (`posix_memalign`, `pthread_join`; `fts_read`'s 0, D-13.14), and a sweep of 40 successful calls that must not leave `errno` 0. **Found and fixed:** `glob(GLOB_ALTDIRFUNC)` left the 0 it stores before each caller callback (to tell a failure from success); the caller's value is now restored after a callback that succeeded and left it 0. (The reference passes the sweep except `getpwuid`, which leaves 0 there.) |
| D-C0.2 | C0.2 | HIST, PATH | Static results live in per-thread slots (P-scope). "Overwritten by the next call" still holds, and cross-thread clobbering disappears (observable, stricter). **Tests (milestone 5):** `conformance/c/s00_threads.c` (MT-Safe by default, static buffers, process-global state; clauses `s0_6_c0_2_0` to `s0_6_c0_2_2`) and `s00_as_safe.c` (a handler interrupting the library 5,000 times; cancellation at `close`; `s0_6_c0_2_3`, `s0_6_c0_2_4`). **Every result per thread (milestone 6, 2026-10-04/05; owner refinement):** the gap found in milestone 5 (`ecvt`/`fcvt`/`qecvt`/`qfcvt`, `l64a`, `tmpnam(NULL)`, `inet_nsap_ntoa`, `rcmd`'s host name, `ttyname`, `ptsname`, `getttyent`, and found since: `getusershell` and the resolver's `p_type`, `p_class`, `p_rcode`, `p_option`, `p_time`, `p_secstodate`, `sym_ntos`, `sym_ntop`, `hostalias`, `loc_ntoa(NULL)`) is closed. Mechanism: one result area per thread, allocated on first use and freed at the thread's exit: one word in the descriptor's slot area (`SLOT_RECORDS`) points to a table of (address, size) per kind (36 kinds: the 14 database records and these 22 texts), each kind's block also allocated on first use (the texts at their fixed size, so a returned pointer stays valid until the next call of that function in that thread). The kinds are not limited by the 17 slots. Never shared: when the area or a block cannot be allocated the function fails: NULL with `ENOMEM` (the pointer results; `getttyent`, `getusershell` with `errno` set), `rcmd` leaves `*ahost` as the caller's name; the fixed slots in the descriptor (`strerror`, `strsignal`, `gmtime`/`localtime`, `asctime`/`ctime`, `getdate`, `inet_ntoa`, `ether_ntoa`/`ether_aton`) exist for every thread Liella starts, and for a thread it adopts and cannot map one: NULL with `ENOMEM`, `getdate_err` 6, or (no error channel) `strerror`/`strsignal` give the constant `Unknown error`/`Unknown signal` with `ENOMEM`; the process-wide fallbacks are removed. `getpass` keeps its one process-wide buffer (MT-Unsafe by contract, serialised with the terminal). Test: `conformance/c/s00_result_buffers.c` (19 functions, two threads at once and eight under load; `getusershell` across threads; heap bytes in use equal after a thread that used them all and one that used none); the reference fails it at the first (`ecvt`). Recorded in `docs/differences-from-glibc.md`. |
| D-C0.3 | C0.3 | KERN, HIST | `EINTR` is surfaced (⚑ KERN), with no hidden retries (X4). `close` is never retried: the descriptor is released even on `EINTR` (spec §11.2 guarantee). |
| D-C0.4 | C0.4 | COMPAT | 64-bit only. Each `*64` name is a second export of the same translation function. 32-bit ABIs are out of scope (OD-10). **Tests (milestone 5):** `conformance/c/s00_largefile.c` (a 5 GiB sparse file through both names of each pair, `struct stat64`/`statvfs64`/`rlimit64`/`dirent64`, `time_t` past 2038) and the products' symbol list against the reference's `*64` names (clause `s0_6_c0_4_0`). |
| D-C0.5 | C0.5 | PATH | **Internal functions always take bounded slices, so fortification is free.** `__x_chk(..., destlen)` builds the destination slice from `destlen` (`abi::chk`). An overflow becomes a detected bound violation that calls `__chk_fail` (spec §2.5). Non-`_chk` forms have no size (F2). Where the amount written depends on the input (`__fgets_chk`, `__fgetws_chk`), C0.5's "would write beyond" is taken literally (phase 8): the read is bounded by the object, and the process terminates only when another unit would have followed a full object; an `n` larger than the object alone does not terminate. The same holds for the bounded printf forms (`__snprintf_chk`, `__vsnprintf_chk`, `__swprintf_chk`, `__vswprintf_chk`): a `maxlen` larger than the object, or an empty object, terminates only when a unit (or the terminator) would land beyond it. The `%n` rule asks where the caller's format lies, also for the wide forms, which convert a copy. **Tests (milestone 5):** clause `s0_6_c0_5_0` runs `s02_chk_fail.c` and `s12_symbols_printf_chk.c` and compares `__memcpy_chk`/`__strcpy_chk` within the object with their base forms. |
| D-C0.6 | C0.6 | COMPAT | The version script is generated from Appendix C.3 (`spec/abi/versions.tsv`), which lists every version and binding. Old contracts live in `legacy::versioned`. Compat-only names are exported with non-default versions (`name@VER`, not `@@`), so new programs cannot link them, matching glibc. |
| D-C0.7 | C0.7 | HIST | Internal APIs encode ownership in types (`TryVec`, `&mut [u8]`, borrowed views). Caller-owned C results come from `boundary::caller_alloc` (F23). Entry points with two ownership modes (`realpath(p, NULL)`, `getcwd(NULL, 0)`) are two internal calls selected by the conversion of the pointer argument (`conv::opt_buf`), not by a branch in the translation. **Tests (milestone 5):** `conformance/c/s00_ownership.c` (clause `s0_6_c0_7_0`): copies of borrowed arguments (`putenv` keeps its string, as stated), heap results measured with `malloc_usable_size` and freed, views inside the caller's object. |
