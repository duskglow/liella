## 3. Memory and string kernels (Zen 1 instruction counts, `bench/instr_limits.tsv`)

The limit file is a regression gate (count + max(2 instr, 2%)), not a claim that the count cannot fall. Rows where Liella is at or below glibc are the closest to saturation; the "ABOVE glibc" rows are named so the owner can see them.
