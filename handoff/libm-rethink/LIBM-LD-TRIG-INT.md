## The change

Decision row: D-NEW "Integer fixed-point quick tier for x87 `long double` and `_Float128`". `sinl`/`cosl` run the
384-bit route on every call today (`crates/math/src/wide.rs` `sin` -> `sin_cos_of`: 80 262 instructions against
glibc's 1119; Ivy Bridge 112.7x in time). Build the first integer fixed-point kernel, shared later with `_Float128`
(one more limb) and the other long double families:

- Unpack the F80 operand to (u64 significand, exponent). Reduction: Cody-Waite in 128-bit fixed point for moderate
  |x|; Payne-Hanek (Payne & Hanek 1983) with a 2/π bit table over the x87 exponent range (about 2 KiB, generated by
  `cargo xtask tables` from the oracle) above; r in [−π/4, π/4] as 128-bit fixed point with the quadrant.
- sin and cos of r: a table of sin(j/64), cos(j/64) as 128-bit fixed point (Tang-style, |r − j/64| < 2^-7) and short
  fixed-point polynomials with exact u64×u64->u128 products (`mul`; `mulx`/`adcx`/`adox` variants only through
  D-10.25's dispatch pattern), bound about 2^-88 (Brent & Zimmermann, Modern Computer Arithmetic, 2010, for the
  multi-limb evaluation).
- Round the 128-bit result to 64 bits in the caller's mode with an integer test (the bound in units of 2^-128): four
  integer roundings, no MXCSR or x87 control-word traffic, so directed modes cost the same.
- Fallback: today's 384-bit route. Deliver kernel + proof + tests + a percall count first; wire it (or cut a -WIRE
  brief) only when the kernel is proven.

## Tests

The sinl/cosl suites in all four modes; seeded random comparison with the 384-bit route over >= 10^7 operands; the x87
arguments closest to multiples of π/2 (compute them with the continued-fraction method, Muller, Elementary Functions,
3rd ed. 2016, ch. 11; do not import lists), tiny and huge arguments, pseudo-denormals and invalid encodings (today's
rules).

## Plants (`cargo xtask plants`, `msg:` per plant)

A 2/π table bit flipped; the quadrant off by one; the rounding test's bound halved; one limb's carry dropped.

## Counts and timing

Percall sinl/cosl against glibc (target <= 300 instructions). x87 rows are judged in cycles (glibc's instructions
include microcoded ones): timing is required, Ivy Bridge and the N100 booked.
